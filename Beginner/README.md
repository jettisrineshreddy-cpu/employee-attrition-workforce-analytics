# Retail Sales Analysis Dashboard

## ShadowFox Data Analyst Internship — Beginner Level

This project is a simple retail sales analysis built in Microsoft Excel as part of the ShadowFox Data Analyst Internship.

I worked with the Madhav E-Commerce Sales Dataset to turn raw order and transaction details into an organized analysis table and a dashboard that gives a quick view of sales performance.

## What I Worked On

The dataset came in two files:

- **Orders** — order date, customer, state and city information
- **Details** — sales amount, profit, quantity, category, sub-category and payment mode

I combined the two files using **Order ID**, checked the data types and structure, and prepared a single analysis-ready table for the rest of the work.

## Analysis

The project covers:

- Total sales and profit
- Total quantity and orders
- Average order value
- Monthly sales trends
- Category performance
- Sub-category performance
- State-wise sales
- Payment-mode usage

## Dashboard

The final Excel dashboard includes:

- Total Sales
- Total Profit
- Total Orders
- Average Order Value
- Monthly Sales Trend
- Sales by Category
- Sales by Payment Mode
- Sales by Sub-Category
- Key Business Insights
- Recommended Actions

## Key Findings

- **January 2018** recorded the highest monthly sales at about **₹61,632**.
- **July 2018** was the lowest-sales month at about **₹12,966**.
- **Electronics** generated the highest sales at about **₹166,267**.
- **Clothing** recorded the highest total profit at about **₹13,325**.
- **Printers** were the strongest sub-category at about **₹59,252** in sales.
- **Maharashtra** had the highest state-level sales at about **₹102,498**.
- **COD** was the most-used payment mode based on quantity.

## What I Learned

This project helped me practice the basics of a real data-analysis workflow:

**Raw Data → Data Preparation → Excel Analysis → Charts → Business Insights → Dashboard**

The main focus was not just creating charts, but understanding what the numbers were showing and turning them into practical business observations.
